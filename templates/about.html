ℹ️ About AI-Powered Phishing Website Detection System

The AI-Powered Phishing Website Detection System is a Machine Learning-based cybersecurity application developed to identify phishing websites using engineered website features. The system classifies websites as Legitimate or Phishing and provides Explainable AI visualizations using SHAP and LIME to improve transparency and trust in model predictions.

🎯 Project Objective

The primary objective of this project is to develop an intelligent phishing website detection system capable of accurately identifying malicious websites using Machine Learning. The application also aims to make predictions more transparent by integrating Explainable AI techniques, enabling users to understand how the model arrives at its decisions.

⚙️ Machine Learning Workflow

  1. Collect website phishing dataset.
  2. Perform data cleaning and preprocessing.
  3. Encode the target labels.
  4. Split the dataset into training and testing sets.
  5. Scale numerical features using StandardScaler.
  6. Train the Random Forest Classifier.
  7. Evaluate model performance using Accuracy, Precision, Recall and F1-Score.
  8. Generate Explainable AI visualizations using SHAP and LIME.
  9. Deploy the trained model using Flask.
