# Phishing Website Detection using Explainable AI

## Overview

A Flask-based web application that detects phishing websites using a Machine Learning model and provides explainable predictions using SHAP and LIME.

## Technologies Used

- Python
- Flask
- Scikit-learn
- SHAP
- LIME
- XGBoost
- HTML
- CSS
- JavaScript

## Features

- Website Prediction
- Confidence Score
- SHAP Explainability
- LIME Explainability
- PDF Report
- Cybersecurity Dashboard
